# Macro Studio

Редактор макросов из визуальных нод. Нажатия мыши и клавиатуры отправляются через системный
`SendInput` (клавиши — сканкодами), поэтому должны доходить и до игр. Только Windows.

Стек: Tauri 2 + React + React Flow (интерфейс), Rust (ядро ввода и горячих клавиш).

## Запуск на Windows

Нужно один раз поставить: [Rust](https://rustup.rs), Node.js 20+, Visual Studio Build Tools
(пакет «Разработка классических приложений на C++»). WebView2 на Windows 10/11 обычно уже есть.

```powershell
npm install
npm run tauri dev      # запуск для разработки
npm run tauri build    # установщик в src-tauri/target/release/bundle/nsis
```

Если игра запущена **от администратора** — запускайте Macro Studio тоже от администратора,
иначе Windows не пропустит нажатия в её окно.

## Что умеет

| Узел | Что делает |
|---|---|
| Старт | Начало макроса (один на макрос) |
| Клавиша | Нажать и отпустить / зажать / отпустить, время удержания |
| Кнопка мыши | ЛКМ, ПКМ, СКМ, X1, X2: клик / зажать / отпустить |
| Движение мыши | В точку экрана (пиксели) или сдвиг от текущей позиции |
| Колесо мыши | Вверх (+) или вниз (−), в щелчках |
| Задержка | Пауза в мс + случайная добавка |
| Цикл | Выход «тело» повторяется N раз (0 — бесконечно), выход «дальше» — после цикла |

Режимы запуска по горячей клавише (клавиатура или кнопки мыши: средняя, X1, X2):

- **Вкл/выкл** — нажал: макрос повторяется по кругу, нажал ещё раз: остановился.
- **Пока зажата** — повторяется, пока держишь кнопку.
- **Один раз** — одно нажатие = один прогон.

Безопасность: клавиша **Pause (Break)** останавливает все макросы. При остановке всё, что макрос
успел зажать (клавиши, кнопки мыши), автоматически отпускается.

Экспорт/импорт: кнопки «Экспорт JSON» и «Импорт». Формат — один макрос в файле (при импорте
принимается и массив макросов).

## Устройство

- `macro-core/` — ядро на Rust без зависимости от Tauri: формат JSON (`model.rs`), проверка графа
  (`program.rs`), выполнение (`engine.rs`), горячие клавиши и фоновый запуск (`hub.rs`), `SendInput` (`win.rs`).
  Тесты: `npm run test:core` (идут на любой ОС, ввод в тестах подменяется записывающей заглушкой).
- `src-tauri/` — оболочка Tauri: команды для интерфейса и события о статусе.
- `src/` — интерфейс (React Flow).

## Известные ограничения

- Игры с античитом могут блокировать программный ввод. Это не обходится.
- Горячая клавиша читается опросом состояния клавиш: не используйте её внутри самого макроса.
- Изменение схемы или настроек останавливает запущенные макросы (перетаскивание узлов — нет).
- Координаты мыши — в пикселях экрана; запись действий мышью/клавиатурой в узлы пока не сделана.
