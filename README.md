# Macro Studio

Программа для макросов мыши и клавиатуры в Windows. Макрос собирается из блоков-«нод» на схеме
и запускается горячей клавишей. Нажатия идут через системный ввод Windows, поэтому их видят
и обычные программы, и игры.

**[⬇ Скачать последнюю версию](https://github.com/HighPolyNeko/MacroStudio/releases/latest)** — файл `Macro.Studio_..._x64-setup.exe`.

## Установка

1. Скачайте `Macro.Studio_..._x64-setup.exe` со [страницы релизов](https://github.com/HighPolyNeko/MacroStudio/releases/latest) и запустите.
2. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите **Подробнее → Выполнить в любом случае**
   (установщик не подписан платным сертификатом).
3. Готово. Дальше программа обновляется сама: при запуске она предложит новую версию, если та вышла.

Нужна Windows 10 или 11.

## Как пользоваться

### Первый макрос за минуту

1. Нажмите **+ Новый** слева.
2. На схеме уже есть узел **Старт** — с него начинается макрос.
3. Добавьте действия: кнопками сверху, **правой кнопкой мыши по пустому месту → Создать**,
   или потяните линию из точки внизу узла и отпустите в пустоте — появится список, и новый узел сразу соединится.
4. Соедините узлы по порядку: тяните линию от нижней точки одного узла к другому
   (можно отпустить прямо на узел — линия встанет во вход).
5. Нажмите на узел — справа его настройки (какая клавиша, сколько ждать и т.д.).
6. Справа в настройках макроса (когда ни один узел не выбран) задайте **горячую клавишу** и **режим запуска**.
7. Нажмите горячую клавишу в игре или программе — макрос запустится.

**Пример — автокликер:** Старт → Цикл (0 = бесконечно) → из выхода «тело» Кнопка мыши (клик ЛКМ) → Задержка 50 мс.
Такой пример уже лежит в программе при первом запуске.

### Узлы

| Узел | Что делает |
|---|---|
| Старт | Начало макроса. Есть всегда, один на макрос |
| Клавиша | Нажать и отпустить / зажать / отпустить; время удержания |
| Кнопка мыши | ЛКМ, ПКМ, колесо, боковые X1 и X2: клик / зажать / отпустить |
| Движение мыши | В точку экрана или сдвиг от текущей позиции. Точку можно выбрать кнопкой **«Выбрать точку на экране»** — просто кликните, куда нужно |
| Колесо мыши | Прокрутка вверх (+) или вниз (−), в щелчках |
| Задержка | Пауза в миллисекундах + случайная добавка, чтобы ритм был не идеально ровным |
| Цикл | Выход «тело →» повторяется N раз (0 — бесконечно), нижний выход — что делать после цикла |

### Режимы запуска

Горячая клавиша — любая клавиша клавиатуры или кнопка мыши (средняя, X1, X2).

- **Вкл/выкл** — нажали: макрос крутится по кругу; нажали ещё раз: остановился.
- **Пока зажата** — работает, пока держите клавишу.
- **Один раз** — одно нажатие = один прогон макроса.

Запустить и остановить макрос можно и кнопкой ▶ / ■ в списке слева.

### Аварийная остановка

Клавиша **Pause (Break)** останавливает все макросы сразу. То, что макрос успел зажать
(клавиши, кнопки мыши), отпускается автоматически. В программе есть и кнопка **«Остановить всё»**.

### Сохранение и обмен макросами

Макросы сохраняются автоматически. Чтобы передать макрос другому человеку или сохранить копию —
**Экспорт JSON**; чтобы загрузить — **Импорт**.

### Обновления

При запуске программа сама проверяет новую версию и показывает, что изменилось. Обновление
скачивается по кнопке **«Обновить»**, а ставится, когда вы нажмёте **«Перезапустить»** — не посреди игры.
Проверить вручную — кнопка **«Проверить обновления»** внизу слева, история изменений — кнопка **i** рядом с версией.

### Если не работает

- **Игра запущена от имени администратора** — запустите Macro Studio тоже от администратора
  (правой кнопкой по ярлыку → «Запуск от имени администратора»), иначе Windows не пропустит нажатия в окно игры.
- **Игры с античитом** могут блокировать программный ввод — это не обходится. Использование макросов
  в онлайн-играх может нарушать их правила, решайте сами.
- **Не используйте горячую клавишу внутри самого макроса** — программа может принять это за повторное нажатие.
- Изменение схемы или настроек останавливает запущенные макросы (перетаскивание узлов — нет).

## Для разработчиков

Стек: Tauri 2 + React + React Flow (интерфейс), Rust (ядро ввода и горячих клавиш). Только Windows.
Клавиши отправляются через `SendInput` сканкодами — так их видят и игры на DirectInput/RawInput.

### Запуск из исходников

Нужно один раз поставить: [Rust](https://rustup.rs), Node.js 20+, Visual Studio Build Tools
(пакет «Разработка классических приложений на C++»). WebView2 на Windows 10/11 обычно уже есть.

```powershell
npm install
npm run tauri dev      # запуск для разработки
npm run tauri build    # установщик в src-tauri/target/release/bundle/nsis
npm run test:core      # тесты ядра
```

### Устройство

- `macro-core/` — ядро на Rust без зависимости от Tauri: формат JSON (`model.rs`), проверка графа
  (`program.rs`), выполнение (`engine.rs`), горячие клавиши и фоновый запуск (`hub.rs`), `SendInput` (`win.rs`).
  Тесты идут на любой ОС, ввод в них подменяется записывающей заглушкой.
- `src-tauri/` — оболочка Tauri: команды для интерфейса, события о статусе, окно выбора точки, автообновление.
- `src/` — интерфейс (React Flow).
- `scripts/` — смена версии во всех файлах и сборка release notes (их вызывают workflow).
- `.github/workflows/` — проверки PR и выпуск релизов.

Формат макроса: один макрос в JSON-файле (при импорте принимается и массив макросов).

### Ветки и релизы

- Новая фича — ветка `feature/...` от `develop`, PR в `develop`. Обязательные проверки: **CI** (сборка и тесты
  на Windows) и **PR title** (заголовок в формате Conventional Commits: `feat: ...`, `fix: ...` и т.д.).
- В описании PR есть раздел **«Для release notes»** — пункты оттуда попадают в список изменений релиза,
  который видят пользователи. Опечатку можно исправить в PR до релиза или в описании релиза на GitHub после.
- Релиз: создать ветку `release/X.Y.Z` от `develop` — бот сам добавит коммит с версией X.Y.Z.
  Открыть PR `release/X.Y.Z` → `develop` и смержить через **Create a merge commit** (не squash).
- После мержа workflow **Release** собирает подписанный установщик, публикует GitHub Release `X.Y.Z`
  с `latest.json` для автообновления, перематывает `main` на коммит релиза и удаляет релизную ветку.
